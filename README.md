# AWS EC2 Nginx Web Server

Deployed a static website on an AWS EC2 Linux instance using Nginx as the web server.

This project demonstrates basic cloud infrastructure provisioning, Linux server management, and web server configuration.

---

## Tech Stack

- AWS EC2
- Linux (Ubuntu)
- Nginx
- SSH
- Networking (HTTP / Security Groups)

---

## Project Overview

A Linux EC2 instance was provisioned on AWS and configured as a web server using Nginx.  
A static website was deployed and made accessible via the EC2 public IP address.

---

## Key Skills Demonstrated

- Launching and managing EC2 instances
- Linux server administration
- Installing and configuring Nginx
- Managing AWS Security Groups
- Hosting a website on cloud infrastructure

---

## Outcome

The website was successfully deployed and served through an Nginx web server running on an AWS EC2 instance.
